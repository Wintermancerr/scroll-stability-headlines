# Scroll Stability headlines

A public, automatically refreshed list of recent news headlines from about 30 outlets across
the political spectrum and around the world. The Scroll Stability app uses it to answer
"who else is reporting this?"

- **What's in it:** headline, link, outlet and time, from each outlet's own public RSS feed.
  No article text is copied.
- **How often:** every 15 minutes, by GitHub Actions.
- **Where:** `news-index.json` on this repository's GitHub Pages site.
- **Outlets:** see `feeds.json`.
